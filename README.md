# Project Priority Matrix

### A simple and efficient approach to prioritize work and projects

To prioritize projects effectively, evaluate each project using the following fields:

1. **Feasibility** – How easy or difficult is the project to complete?
   - Difficult → 1
   - Easy → 10

2. **Impact** – How much impact will the project create?
   - Low Impact → 1
   - High Impact → 10

3. **Size** – How much time or cost will the project require?
   - Less Time/Cost → 1
   - More Time/Cost → 10

> **Note:** The fields and scoring criteria can be modified depending on the type of project or business requirement.

### Visualization in Excel

- Create a **Bubble Chart** using the project size as bubble size.
- Use **Feasibility** on the X-axis.
- Use **Impact** on the Y-axis.
- Format the chart for better readability and presentation.
